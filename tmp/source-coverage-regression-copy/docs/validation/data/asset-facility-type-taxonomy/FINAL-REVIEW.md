## القرار والتعريف

يجيب بُعد **نوع الأصل/المرفق/الموقع** عن السؤال: ما الأصل المادي أو العقار أو المرفق أو نوع الموقع الاستثماري الذي تعرضه الفرصة؟ وهو يظل منفصلًا عن القطاع والنشاط ونوع الفرصة ونموذج الاستثمار والموقع الجغرافي.

```ini

ASSET_FACILITY_TYPE_IS_SINGLE_VALUED = FALSE
LAND_USE_DIMENSION_GAP = FALSE
ASSET_FACILITY_TYPE_DASHBOARD_VISUAL_JUSTIFIED = FALSE
```

الدليل الحاسم هو حقل فرص المنظم `attributes.LOCATIONTYPE`: 177 سجل مصدر، 131 قيمة نوع صريحة قابلة للتطبيع، موزعة على 129 فرصة رئيسية، وثمانية تصنيفات مكررة. هذا استخدام عملي متكرر وذو معنى مستقل عن النشاط ونوع الفرصة. تظهر قيمتان في سجلّي Master مع فئتين للموقع؛ لذلك البعد متعدد القيم. تغطية هذا الحقل تأتي من مصدر فرص وحده، وتصنيفاته تجمع أنواع موقع مثل الحدائق والساحات والطرق مع الأرض والمباني ومواقع العربات المتنقلة. مرشح البعد مفيد، أما رسم يقارنها بوصفها جردًا شاملًا لكل أصول الأحساء فسيبالغ في معنى تغطية المصدر؛ لذلك لم يُضف رسم للبعد.

لا توجد في سجلات المصدر الحالية قيمة منظمة تجيب عن **استخدام الأرض** مستقلًا عن نوع الموقع أو النشاط. «الاراضي» في `LOCATIONTYPE` نوع موقع/عقار، وليست استخدامًا مثل تجاري أو صناعي. لذلك لا يوجد دليل كافٍ على فجوة Land Use مستقلة.

## المعاينة والتطبيق

أنشأ التشغيل الجاف قائمة لكل قيمة `LOCATIONTYPE` مرتبطة بفرصة غير مدمجة، مع Master المصدر، الحقل الخام، الأبعاد الحالية، الاقتراح، الدليل، وحالة القرار. لم يقرأ العنوان لتخمين النوع.

```ini
TOTAL_ELIGIBLE_MASTERS = 291
DETERMINISTIC_ASSET_TYPE_MAPPINGS = 131
WRONG_DIMENSION_VALUES_FOUND = 0
MAPPED_TO_UNSPECIFIED = 0
MASTERS_WITH_DETERMINISTIC_TYPE = 129
MASTERS_WITHOUT_DEFENSIBLE_TYPE = 162
REMAIN_REVIEW_REQUIRED = 0

```

بعد مراجعة الاقتراح، أُدرجت 131 صفًا مشتقًا في `opportunity_asset_facility_types` فقط. لم تُعدّل حقول Master أو SourceOpportunity أو محتواها الخام. الـ162 غير المحددة ليس لها صف placeholder في جدول الإسناد؛ تعرضها واجهات الأعمال بالهوية `asset_facility_type:missing` والاسم «غير محدد». الإسناد قابل لإعادة التشغيل بحسب مفتاح سجل المصدر والنوع، وسيستبدل المعالج إسقاط السجل نفسه في مزامنة مستقبلية بدل تكراره.

القاموس يضم ثمانية أنواع فعلية بالإضافة إلى الهوية الخاصة بالمفقود. Aliases الثمانية كلها مقيدة بـ`furas + LOCATIONTYPE`. لا توجد Alias عامة أو تخمين من النشاط أو العنوان. `أخرى` تختلف عن «غير محدد»: عددهما الحالي 10 و162 على الترتيب.

## API والواجهة والتصدير

بعد الإسناد، قارنت لكل خيار هوية المرشح وعدّاده باستعلام API والقائمة وCSV وXLSX. جميعها متطابقة، وفُحصت أسماء الأنواع في التفاصيل والتصدير. العد متعدد القيم؛ فمجموع عدادات الأنواع الثمانية `131`، بينما عدد Masters الفريدة المصنفة `129`. يضاف 162 غير محدد إلى 291؛ ويكون مجموع عدادات الخيارات المعروضة `293` لأن Masterين يظهر كل منهما ضمن خيارين.

تحقق Playwright من النسخة العربية RTL عند `1920×1080`: المرشح ظاهر، النوع يفلتر إلى Master واحد للمباني، يظهر في صف القائمة والتفاصيل، ويُمرر إلى روابط CSV/XLSX؛ زر إعادة الضبط يعيد 291 فرصة؛ `scrollWidth=1920` بلا تمرير أفقي. اللقطة في `screenshots/asset-facility-type-building.png` والدليل في `screenshots/ui-verification.json`. تحقق التصدير الهيكلي: XLSX من 24 عمودًا، اتجاه الورقة RTL، تجميد `A7`، مرشح `A6:X7`، عمود النوع X بعرض 24، ومنطقة الطباعة A:X.

أضيف مرشح في لوحة البيانات والفرص، وحقل النوع في صف القائمة والتفاصيل وعمود XLSX/CSV الموجود. لم يضف رسم تحليلي. كانت حاوية Nginx تخدم HTML وJavaScript أقدم من مساحة العمل؛ احتُفظ بنسختيهما قبل استبدالهما داخل الحاوية دون بناء صورة جديدة. نسخة الرجوع في `live-static-before/`. فحص Nginx نجح، وhealth readiness أكد قاعدة البيانات وRedis والعامل. بقيت خدمات API وWorker وBeat على إصدار المحرك 16.

## الإدخال المستقبلي والسلامة

- نوع معروف في Furas `LOCATIONTYPE` أو Alias معتمد من الحقل نفسه ← هوية أصل معيارية ثابتة.
- نشاط فرعي معروف مثل `محلات تجارية` في حقل النشاط الفرعي ← يبقى نشاطًا فرعيًا ولا يصبح أصلًا.
- حقل نوع أصل فارغ ← لا ينشأ إسناد؛ تعرض الواجهة «غير محدد».
- قيمة `LOCATIONTYPE` جديدة ← لا تخمين؛ تبقى غير محسومة وتدخل تعارض نوع أصل للمراجعة عند ورود السجل عبر المعالج.
- نص أصل محتمل في مصدر أو حقل آخر (مثل `activity=برج مياه`) ← لا Alias أصل؛ يبقى ضمن دلالات المصدر/النشاط.
- قيمة Sector أو Opportunity Type أو Investment Model ← لا تُدرج في نوع الأصل بسبب تشابه النص.

فحص البيانات قبل تحديث المرشح وبعده طابق SHA-256 لـ296 هوية Master، و2,898 رابطة مصدر، و2,898 حمولة مصدر، و7,603 هوية/حمولة ملاحظة، و1,012 سجل تاريخ تغيير، و96 تعارضًا مفتوحًا، و0 مراجعة تأهيل مفتوحة. لم تتغير هوية Master أو SourceOpportunity links أو المحتويات الخام أو طوابير التصنيف القائمة. لم يبدأ طلب مزامنة يدوي. ظلت قوائم Celery `active`, `reserved`, `scheduled` فارغة عند الفحص.

أُصلحت في مساحة العمل أداة مطابقة الكيانات حتى لا تسمي `SUBACTIVITYTYPE` نوع أصل؛ تقرأ الآن فقط الحقول التي يعتمدها مستخرج النوع ذو النطاق المصدر/الحقل. لا يغير ذلك أي تعيين قائم. لا توجد قيم موقع معروفة متسربة إلى Sector أو Activity أو Sub-Activity أو Opportunity Type أو Investment Model. بقيت الكلمات العامة مثل «أخرى» بقيمها الخاصة بكل بُعد.
