# التحقق من واجهة شعارات المصادر الرسمية

تاريخ التنفيذ: 2026-10-14.

أُضيفت شعارات ناشري المصادر السبعة التي أمكن التحقق منها من ملفات المشروع أو نطاقاتها الرسمية، مع بدائل نصية محايدة لفرص الأحساء وNHC وPIF. المرجع الكامل للمفاتيح والأصول الرسمية وملفاتها وبصماتها في [نظام شعارات المصادر الرسمية](../../design/source-logo-system.md).

تعرض بطاقة كل مصدر فرص الأحساء الموحدة المرتبطة بها عند فتحها، وتُحمّل 50 فرصة في المرة. يحمل كل صف شعار بطاقة المصدر نفسها وفق مفتاح المصدر، ويحتفظ بزر تفاصيل الفرصة ورابط الإعلان الأصلي عند توفره. لم تُنفذ مزامنة، أو تغيير لبيانات قاعدة البيانات، أو تعديل لمنطق الصحة والتغطية.

## نتائج التحقق

- **المصادر:** ظهرت جميع البطاقات العشر. تطابقت مفاتيح المصدر مع خريطة الشعار المركزية.
- **الأصول:** سبعة شعارات رسمية محلية؛ جميع صور الشعارات السبع أعادت `naturalWidth > 0`. ثلاثة مصادر تعرض بدائلها النصية الموثقة. لم يظهر رمز صورة مكسورة.
- **قوائم الفرص:** جُرّبت مصادر فرص، والأحساء المحلية، وAHDA، واستثمر في السعودية، وKFU، وNCP. احتفظت الصفوف بعنوان الفرصة وبياناتها ورابط الإعلان، وأظهرت شعار الناشر الصحيح بجوار العنوان. أظهرت MODON وNHC وPIF وموان الحالة الفارغة دون اختلاق فرص.
- **المظهر والإتاحة:** اتجاه RTL صحيح، الشعار لا يتشوه ويحافظ على حجمه، العناوين تلتف، وكل شعار له اسم وصول وتلميح. عند اختبار ملف غير موجود أخفت الواجهة `<img>` وأظهرت البديل.
- **الشاشات الضيقة:** عند 390×844 بقيت البطاقات بعمود واحد، وظل الشعار بعرض 30px والعنوان قابلًا للعرض بجانبه.
- **التحقق البرمجي:** فحص صياغة JavaScript ناجح، واختبارات العقد **3/3**، ومجموعة المشروع **113 اختبارًا ناجحًا**. `/health/ready` وملفات الواجهة والأصل المحلي أعادت HTTP 200.
- **قاعدة البيانات:** لم تُشغل مزامنة؛ لا تغيير في الفرص أو المراجعات أو منطق التغطية والصحة. أُعيد بناء خدمة الواجهة فقط.
