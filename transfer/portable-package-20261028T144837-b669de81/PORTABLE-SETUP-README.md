# نقل المنصة إلى جهاز جديد

## على الجهاز الحالي

1. شغّل **Prepare Transfer.bat**.
2. أنشئ عبارة مرور نقل خاصة لا تقل عن 16 حرفًا واحتفظ بها لإدخالها على الجهاز الجديد.
3. انتظر رسالة **TRANSFER PACKAGE READY**.
4. انسخ مجلد `transfer\portable-package-<package-id>` كاملًا إلى الجهاز الجديد. هذا المجلد هو نسخة مشروع كاملة للنقل؛ لا تنسخ مجلد المصدر الخام الذي يحتوي الإعدادات المحلية وملف دخول المسؤول.

يتضمن مجلد الحزمة نسخة PostgreSQL منطقية مشفّرة التنسيق ومتحققًا منها، والمصدر والترحيلات والوسائط والشهادات وسجل التحقق. يستثني ملف `.env.local` وملف بيانات دخول المسؤول ونسخة SQLite القديمة والنسخ السابقة والسجلات والذاكرة المؤقتة. يُشفّر مفتاح توقيع الجلسات داخل `transfer\private` بعبارة المرور التي أنشأتها.

## على الجهاز الجديد

1. ضع مجلد الحزمة في أي مسار تملكه، مثل `C:\Sharakat Data Base`.
2. انقر بزر الفأرة الأيمن على **Setup Platform.bat** ثم اختر **Run as administrator**. عند التشغيل العادي يطلب الإعداد صلاحية Windows UAC بنفسه.
3. أدخل عبارة مرور النقل. لا تُسجل العبارة في ملفات التحقق.
4. إذا ظهرت الرسالة `يجب إعادة تشغيل الجهاز ثم تشغيل Setup Platform.bat مرة أخرى`، أعد تشغيل Windows ثم شغّل الزر نفسه مجددًا.
5. عند ظهور **PLATFORM SETUP COMPLETE** افتح `http://localhost:8080`.

يتحقق الإعداد من بصمات الملفات، ولا يستعيد فوق قاعدة موجودة. إذا تعطّل أثناء الاستعادة، يحفظ حالة الاستئناف؛ يعيد التشغيل استخدام قاعدة تطابق الحزمة، أو ينشئ اسم مشروع جديدًا ويُبقي بيانات المحاولة الجزئية دون حذف.

## أزرار التشغيل

- **Start Platform.bat** — تشغيل الخدمات وفتح المنصة.
- **Stop Platform.bat** — إيقاف الخدمات مع حفظ قاعدة البيانات.
- **Restart Platform.bat** — إعادة تشغيل الخدمات.
- **Platform Status.bat** — عرض حالة الخدمات.
- **Verify Installation.bat** — تحقق صحي وقراءة فقط، دون مزامنة مصادر.
- **Check New PC.bat** — فحص متطلبات الجهاز قبل التثبيت.

## المتطلبات

Windows 11 x64، وWSL2، وDocker Desktop مع Compose v2. لا يحتاج المستخدم تثبيت Python أو PostgreSQL أو Redis أو Node أو Celery أو Nginx على Windows. عند غياب WSL2 أو Docker Desktop يستخدم الإعداد ميزات Windows وWinGet الرسمي؛ وإذا تطلب WSL إعادة التشغيل، يستأنف الزر بعد إعادة التشغيل. يحتاج وضع الإعداد القياسي اتصالًا بالإنترنت لتنزيل صور Docker عند عدم وجودها محليًا.

لا يفتح الإعداد منافذ Windows للجمهور. واجهة المنصة ترتبط بـ`localhost:8080`، وتبقى PostgreSQL وRedis داخل شبكة Compose الخاصة.

**البيانات الحساسة:** ملف النسخة المنطقية يحتوي سجلات المنصة وتجزئات كلمات المرور؛ تعامل مع مجلد النقل كبيانات خاصة. لا تحتوي ملفات التقارير على كلمات المرور أو محتوى ملف البيئة.
