# إصلاح قص شريط مرشحات الفرص الاستثمارية

**الحالة:** `OPPORTUNITY_FILTER_TOOLBAR_CLIPPING_FIX_COMPLETE`

## التغيير

- استبدال توزيع شريط المرشحات المرن ذي العروض الذاتية بشبكة RTL ذات أعمدة مرنة و`min-width: 0`، مع حجز مساحة كافية لزر **إعادة الضبط** ومنع التفاف عنوانه.
- عند اتساع الشاشة (1601px فأكثر) تبقى عناصر الشريط العشرة في صف واحد. عند 1440 و1366px يلتف الشريط عمدًا إلى ثلاثة صفوف، وعلى 768 و390px يستخدم عمودين مع وضع البحث والزر على عرض الصف.
- حصر اتجاه التمرير الأفقي لجدول الفرص داخل حاويته مع إبقاء الجدول RTL؛ وبذلك لا يمتد عرض الصفحة أفقيًا على الهاتف.
- لم تتغير سلوكيات المرشحات أو APIs أو بيانات الأعمال أو لوحة البيانات.

## التحقق

فُحصت المقاسات 1877×1033 (مطابقة لحجم الصورة المرفقة)، 1920×1080، 1440×900، 1366×768، 768×900، و390×844. في كل مقاس بقيت عناصر الشريط العشرة داخل الحاوية، بلا قص أو تداخل، وظهر نص «إعادة الضبط» كاملًا، وظل اتجاه RTL صحيحًا. عرض المستند يساوي عرض الشاشة في جميع المقاسات، وأمكن الوصول إلى عناصر الاختيار وفتحها.

نجحت اختبارات التصفية ومطابقتها لنتيجة API، وإعادة الضبط، والبحث، والتنقل بين الصفحات، وتصدير CSV وXLSX، وفتح تفاصيل الفرصة. لم تسجل أخطاء متصفح أو طلبات فاشلة في جولة التحقق النهائية.

- لقطة الشاشة النهائية: [opportunities-filter-toolbar-1877x1033.png](screenshots/opportunities-filter-toolbar-1877x1033.png)
- نتائج القياس التفصيلية: [qa-summary.json](screenshots/qa-summary.json)

الخدمات المحلية باقية عاملة وفحص الجاهزية يعيد `ready`. لم تُشغّل مزامنة ولم تُمس قاعدة البيانات المحلية أو بيانات الفرص ومراجعاتها.
