# أدلة الواجهة المرئية

التقطت هذه الصور من `http://localhost:8080` ببيانات المنصة الحية، عبر Edge وPlaywright. لقطات الصفحات الأساسية بحجم 1440×900، عدا 05 و06 فهما قصاصتان فعليتان لبطاقة المراجعة الأولى لتوضيح المقارنة ومعلومات الموقع. لقطة الدخول دون إدخال اعتماد؛ التقطت الصفحات الخاصة بعد دخول المسؤول. لم تُنفذ إجراءات مراجعة أو إدارة تكتب في البيانات.

تتضمن `01-login.png` و`02-dashboard.png` و`11-app-shell.png` نسختي شعار الهيئة الرسميتين بعد جلبهما مباشرة من موقعها ودمجهما في شاشة الدخول والشريط الجانبي. أعيد التحقق بصريًا من هذه المواضع بعد بناء الواجهة النهائي في 2026-10-13؛ النسخة الأساسية للسطح الفاتح والمعكوسة لشريط Depth. بقية لقطات الوظائف لم تتغير في هذه الجولة.

- `01-login.png` — شاشة الدخول، دون إدخال اعتماد.
- `02-dashboard.png` — لوحة المؤشرات.
- `03-opportunities.png` — قائمة الفرص.
- `04-opportunity-detail.png` — ملف فرصة حي.
- `05-duplicate-review.png` — مقارنة التكرار جنبًا إلى جنب.
- `06-location-review.png` — أدلة الموقع والإجراء المتاح.
- `07-conflicts.png` — تعارضات الحقول.
- `07b-taxonomy-conflicts.png` — تعارضات التصنيف.
- `08-sources.png` — تغطية المصادر وصحتها.
- `09-alerts.png` — مركز التنبيهات الحالي.
- `10-admin.png` — صحة الخدمات والجدولة والإدارة.
- `02-dashboard-1366.png`, `03-opportunities-1366.png` — فحص 1366×768.
- `02-dashboard-1920.png`, `03-opportunities-1920.png` — فحص 1920×1080.
- `12-data-dashboard.png` — لوحة عرض البيانات التنفيذية الحية بعد دمج Ahda Text، التُقطت من نافذة Chrome المتاحة (1165×914)؛ لا تخلط بينها وبين `02-dashboard.png` التي تعرض لوحة المؤشرات.

تمت مراجعة الصور بعد التقاطها. عرض المستند لا يتجاوز العرض عند 1366 و1920؛ جدول الفرص يلتف داخل منطقة التمرير الأفقية المخصصة. أزيل النص التقني الإنجليزي من ملخص بطاقة الإدارة وأصبح خلف «تفاصيل تقنية».


- `13-official-sources-logos.png` — بطاقات المصادر الرسمية وشعار الناشر بجوار عناوين الفرص الموحدة (2026-10-14).
