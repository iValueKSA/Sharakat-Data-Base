## ملخص التنفيذ

أُعيد تصميم لوحة **منصة الفرص الاستثمارية في الأحساء** داخل التطبيق المحلي القائم. بقي FastAPI وPostgreSQL وRedis وCelery وواجهات API الحالية هي أساس النظام؛ بقي مسار اللوحة `/?view=data-dashboard`، ولم يُنشأ تطبيق أو منفذ إضافي. التصميم يستعير أنماطًا عامة من NextAdmin مثل التسلسل البصري للوحة، بطاقات المؤشرات، شبكة التحليلات، القائمة الجانبية المتجاوبة، حالات التحميل، والمسافات والحدود المتسقة. لم يُنسخ كود NextAdmin؛ لم يظهر ملف ترخيص في النسخة المحلية المرجعية، لذلك أُعيد تنفيذ الأنماط ضمن CSS وJavaScript الحاليين.

## البنية وقرار الدمج

- الواجهة الموجودة ملفات HTML/CSS/JavaScript ثابتة (`app/static`) تُخدم عبر FastAPI والواجهة الأمامية في Docker/Nginx؛ اختيار إعادة تنفيذ الأنماط في الواجهة الحالية هو الأقل مخاطرة ويحافظ على التطبيق والمصادقة والتشغيل المحلي.
- التجميعات الحية تُحسب في `/api/data-dashboard` على سجلات الفرص الرئيسية غير المدمجة؛ قائمة الفرص تستمر بترقيم صفحات خادمي وبحد 50 سجلًا للصفحة. لا توجد API تجريبية أو قاعدة بيانات موازية.
- روجعت أنماط NextAdmin للصفحات والبطاقات والرسوم والقوائم والتنقل المتجاوب والتحميل والإتاحة. لا تعتمد الواجهة النهائية على مكتبات أو أصول أو هوية NextAdmin.

## التغييرات

- **الملفات المعدلة:** `app/main.py`، `app/standardization.py`، `app/static/index.html`، `app/static/app.js`، `app/static/styles.css`، `tests/test_data_dashboard.py`، `scripts/start-platform.ps1`.
- **هذا التقرير:** `docs/validation/ui/nextadmin-ahda-dashboard/README.md`.
- لم تُضف أو تُحذف تبعيات. لا تغييرات على هوية الفرص أو سجلات المصدر أو قرارات المراجعة.
- أضافت API معرفات القيم القانونية، تصنيفات النشاط والنوع، الحالات المفقودة القابلة للترشيح، مرشحات الفترة والقطاع الفرعي ودورة الحياة، وتطبيق المرشحات على التصدير. أُصلح بناء استعلام المعرّفات بحيث تحترم تجميعات المصدر المرشحات، ومعالجة شرط القيم المفقودة في SQL.
- عُدّل فحص ترحيلات بدء التشغيل ليتحقق من توافق كل رؤوس Alembic المعرفة في المشروع مع النسخة الحالية بدل اشتراط رقم ترحيل ثابت؛ الإصدار الحالي `0017_data_standardization (head)`.
- أضيفت لوحة RTL بعشرة أقسام تحليلية، وبطاقات مؤشرات، ورسوم القطاع والحالة والجهة والمصدر والنوع والنشاط والموقع والمساحة، وخط زمني، ومواعيد، واكتمال البيانات، وجودة البيانات، وصحة المصادر وتغطيتها، وأمثلة السجلات متعددة المصادر. القيم الخام غير المعروفة لا تُخفى أو تُحوّل إلى بيانات تجريبية.
- المرشحات تشمل الفترة، القطاع، الحالة، المصدر، الجهة، الموقع، نوع الفرصة والنشاط الفرعي. روابط الرسوم والمؤشرات تفتح قائمة الفرص مع المرشح المطابق؛ فلاتر غياب القيمة تعمل كذلك. أُصلح رابط بطاقة المواعيد وشرائحها لتطبيق حالة «نشطة» نفسها التي تستخدمها تجميعة اللوحة.
- التصدير يستخدم CSV/XLSX الحاليين ويحفظ مرشحات اللوحة. بقي البحث، صفحات القائمة، تفاصيل الفرصة وصحة المصادر ضمن التطبيق نفسه.
- استُخدمت ألوان AHDA وخط Ahda Text والشعار المحلي الموجود، والاتجاه العربي RTL. القائمة الجانبية تظهر يمين الشاشة، وتتحول إلى درج في أحجام الهاتف واللوحي. لا أدوات زينة غير عاملة.

## الاختبارات والسلوك

- اختبارات المشروع الخلفية/API: **121 ناجحة**. لم تتغير الشفرة الخلفية في الإصلاح النهائي لمرشح المواعيد؛ بعده أُعيد فحص التفاعلات في المتصفح.
- فحص لوحة المتصفح بعد آخر بناء: لا أخطاء JavaScript، ولا استجابات API فاشلة ضمن المسارات الطبيعية. طلب التحقق من جلسة الضيف الذي قد يرجع 401 متوقع للمستخدم غير المسجل.
- فلاتر القطاع وإعادة الضبط والمؤشرات والرسوم والحالات المفقودة والمصدر والجهة والموقع والنوع، الترقيم، البحث، تفاصيل الفرصة، المصدر، والتصدير اجتازت الفحص.
- CSV: تنزيل صالح بحجم 157,024 بايت ويتضمن عناوين عربية. XLSX: تنزيل صالح بحجم 212,101 بايت وبنية ZIP صحيحة. اختُبرت روابط التصدير مع مرشح القطاع؛ كلاهما احتفظ به.
- حساب الضيف لم ينتقل إلى قائمة المراجعة المحمية. لم تُستبدل المصادقة أو RBAC.
- درج التنقل في الهاتف واللوحي يفتح، ينقل التركيز إلى عناصره، ويغلق بـEscape مع إعادة التركيز إلى زر القائمة. نافذة التفاصيل تغلق بـEscape. لم يتغير عقد المصادقة أو صلاحيات الإدارة.

## التشغيل المحلي وحفظ البيانات

- أُعيد تشغيل المنصة عبر `Restart Platform.bat` بعد بناء الواجهة. توقف التشغيل السابق بنجاح مع الحفاظ على البيانات، ثم اجتاز التشغيل فحص الخدمات والترحيلات والجاهزية والمجدول؛ انتهى بـ **Platform is ready** وفتح العنوان المحلي.
- تكرر `Start Platform.bat` أثناء التشغيل، فاكتشف الخدمة القائمة وفتحها دون إنشاء تشغيل مكرر. أظهر `Platform Status.bat` أن Docker وPostgreSQL وRedis وAPI والواجهة والعامل والمجدول والجاهزية كلها `RUNNING`.
- `/health/ready` أعاد HTTP 200 مع قاعدة البيانات وRedis والعامل `ok`. Alembic عند `0017_data_standardization (head)`.
- لم يُنفذ مزامنة أو تعديل أو دمج أو حذف لسجلات الفرص أو قرارات المراجعة ضمن هذه المهمة. بقاء المجدول يعمل يعني أن الأعداد قد تتغير مع مزامنات المصادر الطبيعية.

## الحدود المتبقية

- النشاط الفرعي غير مملوء في السجلات الـ289 الحالية؛ الرسم يعرض ذلك كقيمة مفقودة بدل اختلاق توزيع. اكتمال القطاع 57.1%، والمرجع 63.0%. هذه فجوات بيانات حقيقية.
- مصدر واحد في الحالة `WARNING` وفق بيانات صحة المصدر الحالية؛ تعرضه اللوحة منفصلًا عن تغطية المصدر. لا يمنع ذلك عمل اللوحة.
- أصول عائلة الأيقونات والنقوش الرسمية غير موجودة ضمن ملفات المشروع المقدمة؛ تُستخدم رموز واجهة بسيطة موجودة بدل الادعاء بأنها أصول AHDA الرسمية. نظام الألوان والخط والشعار المحلي محفوظة.
