# إعادة بناء لوحة بيانات AHDA بأسلوب Tabler

**الحالة:** `TABLER_AHDA_DATA_DASHBOARD_REBUILD_COMPLETE`  
**المسار:** `/?view=data-dashboard`  
**تاريخ التحقق:** 2026-10-14

## ما أزيل

- حُذف ملف العرض القديم `app/static/dashboard-visual-analytics.js` بعد نقل رسم اللوحة والخريطة إلى الوحدة الجديدة.
- أزيلت دوال رسم اللوحة القديمة ومراجع عناصرها من `app/static/app.js`، مع إبقاء تحميل البيانات والمرشحات والتصدير والتنقل والتفاصيل في طبقة التطبيق القائمة.
- استُبدل محتوى شاشة اللوحة القديمة في `app/static/index.html` مع الحفاظ على معرّف العرض ومسار التنقل الحاليين.
- حُذفت قواعد العرض القديمة الخاصة باللوحة من `app/static/styles.css`. بقيت قواعد التطبيق المشتركة، وأصبحت قواعد اللوحة في ملف مستقل محدود النطاق.

لم أضف Bootstrap أو مكتبة رسوم. الواجهة مبنية على HTML وCSS وJavaScript الموجود، والرسوم المتجهية SVG، وLeaflet المثبّت محليًا.

## ما أعيد بناؤه

- رأس تنفيذي ومرشحات قابلة للطي وتصدير CSV وExcel.
- بطاقة ملخص، مؤشر إجمالي مع sparkline، حلقة شعاعية لنسبة النشط، وشريط صحة للمصادر.
- مؤشرات موجزة للقطاعات واكتمال الجهة والمواعيد والتغطية الجغرافية، إلى جانب مؤشرات المراجعات وصحة المصادر والمواقع غير الممثلة.
- أعمدة للقطاعات والأنواع، حلقة للحالات، ترتيب أفقي للجهات، وترتيب مصغر للمصادر.
- خريطة الأحساء بعناقيد المواقع وخيار خريطة الكثافة، مع لوحة تغطية وإسناد مرجعي وحدود الاستخدام.
- أقرب المواعيد، جودة اكتمال الحقول، أحدث الفرص، وعينات الفرص متعددة المصادر.
- حين لا تتوفر إلا فترة زمنية واحدة، تعرض البطاقة عدد تلك الفترة وسبب عدم رسم اتجاه زمني؛ لا تُعرض محاور فارغة أو قيم تقديرية.

استُلهمت الشبكة والبطاقات والحدود والمساحات من تنفيذ Tabler وصفحاته التجريبية. لم يتضمن المرفق النصي صورة مرجعية منفصلة، لذلك لم يكن ممكنًا إجراء مقارنة بصرية مباشرة مع لقطة المستخدم نفسها؛ أُجريت المراجعة مقابل مواصفات الصورة المكتوبة وتنفيذ Tabler الفعلي.

## سجل الرسوم ومصادرها

| العرض | النوع | المقياس | API | الانتقال |
|---|---|---|---|---|
| إجمالي الفرص | رقم مع sparkline | الإجمالي والإضافات الشهرية | `/api/data-dashboard`؛ `kpis` و`timeline` | قائمة الفرص |
| نسبة الفرص النشطة | حلقة شعاعية | النشط من إجمالي الفرص | `/api/data-dashboard`؛ `kpis` | قائمة الفرص النشطة |
| صحة المصادر في المؤشر | شريط تقدم | السليم تقنيًا من المصادر المفعلة | `/api/data-dashboard`؛ `sources` | صفحة المصادر |
| القطاعات | أعمدة رأسية | عدد الفرص حسب القطاع | `/api/data-dashboard`؛ `by_sector` | قائمة مفلترة بالقطاع |
| الحالات | مخطط حلقي مع دليل | عدد الفرص حسب الحالة | `/api/data-dashboard`؛ `by_status` | قائمة مفلترة بالحالة |
| أنواع الفرص | أعمدة رأسية | عدد الفرص حسب النوع | `/api/data-dashboard`؛ `by_type` | قائمة مفلترة بالنوع |
| المصادر | قائمة ترتيب مع مسارات تناسبية | الفرص المرتبطة بكل مصدر | `/api/data-dashboard`؛ `by_source` | قائمة مفلترة بالمصدر |
| الجهات المالكة | ترتيب بأشرطة أفقية | عدد الفرص حسب الجهة | `/api/data-dashboard`؛ `by_owner` | قائمة مفلترة بالجهة |
| الإضافات عبر الزمن | مؤشر فترة واحدة حاليًا؛ خط/مساحة عند توفر فترتين أو أكثر | تاريخ أول ظهور وعدد الإضافات | `/api/data-dashboard`؛ `timeline` | قائمة مفلترة بالفترة عندما يتوفر نطاق زمني |
| التغطية الجغرافية | خريطة بعناقيد أو كثافة | النقاط المطابقة وملخص التغطية | `/api/data-dashboard/geography` | قائمة بمعرّفات النقاط الظاهرة على الخريطة |
| اكتمال البيانات | أشرطة تقدم | نسبة توفر كل حقل | `/api/data-dashboard`؛ `completeness` | شاشة مراجعة البيانات |

تُجمّع الفئات الأقل عددًا في «بقية القطاعات/الأنواع» فقط لتقليل ازدحام الرسم؛ يبقى الإجمالي مأخوذًا من استجابة الـAPI.

## سلامة البيانات

- لم تُغيّر بيانات الأعمال أو الفرص أو المراجعات أو الإحداثيات، ولم تُشغّل مزامنة.
- بقيت قاعدة البيانات والـAPI وRedis والعامل والمجدول كما كانت؛ أُعيد بناء وتشغيل خدمة الواجهة فقط.
- بقيت لقطة API قبل/بعد التحقق: **289** فرصة، **283** نشطة، **10** مصادر مفعلة؛ تغطية الخريطة **175** نقطة مطابقة و**114** غير ممثلة. أكدت الشاشة أن إجمالي القطاع بعد المرشح يطابق API وأن ملخص الخريطة بعد المرشح يطابق endpoint الجغرافي.
- يظل الحد الجغرافي مرجعًا محليًا وليس حدًا رسميًا مساحيًا أو تخطيطيًا، وفق توثيق بيانات الخريطة.
- لا تتوفر إلا فترة شهرية واحدة في `timeline` الحالي؛ لذلك لم يُنشأ خط اتجاه مصطنع.

## التحقق المتجاوب والبصري

التقطت الصور كاملة الصفحة، وفُحصت بصريًا. لم يظهر تمرير أفقي، ولم تتجاوز البطاقات أو نصوص العناوين والأسماء المفحوصة حدودها في أي مقاس:

| 1440×900 | 1440 | سليم | لا |

## الانحدار الوظيفي وحالة الخدمات

نجحت فحوص المتصفح للمرشح وإعادة الضبط ومطابقة التجميعات والخريطة مع API، وانتقال الحالة والجهة والنقطة الجغرافية، وتبديل العناقيد والكثافة، والتفاصيل، والبحث، وتقسيم قائمة الفرص، وCSV وXLSX. نجح التنقل إلى الفرص والمصادر والمراجعة والتنبيهات والإدارة؛ أخفى RBAC الإدارة للزائر وأظهرها بعد تسجيل الدخول المحلي. لم تسجل الجولة أخطاء صفحة أو فشل طلبات API.

أعادت `/api/health` الحالة `ok`. أكد `Platform Status.bat` أن Docker وPostgreSQL وRedis وAPI وFrontend وWorker وScheduler وReadiness جميعها `RUNNING`. لم تُشغّل ملفات البدء أو الإيقاف أو إعادة التشغيل، ولم تُنفذ اختبارات الباكند القديمة؛ لم يتغير backend.
