# إصلاح ملخص واجهة الطيار

**الحالة: مكتمل — 2026-10-25.** أُعيد إنتاج خطأ الملخص وأُصلح مسار بناء الاستجابة فقط، مع تعديل عداد الواجهة ليعرض ترتيب الحالة ضمن مرحلتها. بقيت عينة الطيار المجمدة دون تعديل.

## السبب والإصلاح

قبل الإصلاح، أعاد `GET /api/admin/review-workbench/pilot` الحالة **500** والجسم `{"detail":"id","request_id":null}`. أثبت تتبع المكدس أن الخلل في إنشاء `natural_jobs_after_start`: الاستعلام يحدد `(SyncJob, Source.source_key)` ويعيد صفوف SQLAlchemy ثنائية، لكن القائمة كانت تتعامل مع الصف كله كأنه كائن `SyncJob` وتقرأ `job.id`. عند وجود تشغيلات بعد خط أساس الطيار، لا يملك الصف المركب الخاصية `id`.

عُدّل التكرار لفك الزوج إلى `(job, source_key)`. وأضيف تحقق لعقد ملف cohort قبل بناء الملخص؛ العنصر الناقص أو غير المتسق يعيد 503 برسالة واضحة بدل خطأ KeyError. الملخص يعيد بصمة SHA-256، وإحصاءات العينة والمرحلتين والتقدم، ومراجع التنقل للمرحلة الحالية فقط. تبقى المرحلة B غير معروضة حتى حدث مراجعة المرحلة A الذي يتطلب اكتمالها وفق التدفق القائم.

## التحقق من endpoint والعينة

أعاد endpoint الحي بعد النشر **HTTP 200**. يعرض 40 حالة، و20 لكل مرحلة، والمرحلة الحالية A، والمكتمل 0 والمتبقي 40، والمتبقي في A هو 20، وحالات تحقق المصدر في العينة 0، وحالات التكرار 6. أول مرجع نشط هو `duplicate:32` بترتيب A رقم 1؛ لم تُرجع الاستجابة أي مراجع من B.

بصمة cohort قبل/بعد متطابقة:

`E72CB979EBD28E18F302FFA9C1453B2B290496679B83B8ED4CEF34AAC6815C8C`

`PILOT_COHORT_FINGERPRINT_CHANGED = FALSE`

## التنقل والواجهة

اختُبر المسار **Review Queue → Pilot Mode → Phase A → Case 1 of 20** في Playwright. ظهر `الحالة 1 من 20 · المرحلة أ` وفتح المرجع `duplicate:32`. حُجبت المرحلة B من الحالة النشطة ومراجع التنقل، وظل عنصر اعتماد مراجعة A مخفيًا لأن المرحلة غير مكتملة.

نجح الاختبار عند 1920×1080 و1440×900 و1366×768 و768×900 و390×844: اتجاه RTL صحيح، دون تمرير أفقي أو أخطاء JavaScript. لا تملك جلسة المتصفح المحلية دور محلل؛ ضُبط دور العرض داخل ذاكرة صفحة الاختبار فقط لإظهار مسار المراجعة. اعترض Playwright طلبي POST (بدء/استئناف الطيار وإشعار التوصية) وأعاد استجابة اختبارية؛ لم يصل أي طلب كتابة إلى الخادم.

## الاختبارات وسلامة الحالة

- المركزة: **53 ناجحًا / 0 فشل** من `tests/test_review_workbench.py`، وتشمل الملخص الصحيح، والتحقق من cohort غير الصالح، وعدّ المرحلتين، وبصمة العينة، والاحتفاظ بحالات التكرار، وصفر إحالات مصدر، وعدم إعادة توليد العينة، وعزل المرحلة B.
- الانحدار الكامل المعزول: **501 ناجحًا / 0 فشل** على SQLite مؤقتة وحاوية بلا شبكة؛ 33 تحذير إزالة إهمال من الاعتماديات.
- الخدمات بعد النشر: API صحي، والواجهة وPostgreSQL وRedis والعامل والجدول الدوري تعمل؛ لا توجد مهمة مزامنة نشطة.
- حالة الأعمال والمراجعات بعد التحقق: 547 فرصة، 3,138 سجل فرصة مصدر، 10 مراجعات تكرار معلقة، 21 سجل دمج؛ لم يرسل الاختبار أي قرار أو إعادة فتح.

سجل المهام يحتوي تشغيلين تلقائيين مجدولين قبل/حول بداية التحقق: 474 (Furas) و475 (منصة الأحساء). اكتمل كلاهما بنجاح مع **0 سجلات جديدة و0 تحديثات أعمال** (460 بلا تغيير). ازداد عدد ملاحظات المصدر من 23,528 إلى 23,587 ضمن سجل الرصد؛ ولم يتغير عدد سجلات الأعمال أو الماستر. لم يبدأ هذا العمل مزامنة يدوية أو يستدعِ مهمة مصدر.
