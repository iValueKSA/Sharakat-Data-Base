# نموذج أولوية المراجعات

يُشتق التصنيف عند عرض القضية ولا يُخزَّن كقيمة يدوية؛ لذلك يظل حتميًا على البيانات نفسها.

| الأولوية | القاعدة الحالية |
|---|---|
| P1 | فرصة حالية منشورة مع موعد تقديم خلال 0–7 أيام. |
| P2 | فرصة حالية، أو قضية تكرار، أو تعارض حقل/تصنيف. |
| P3 | قضية لا تحقق قواعد P1/P2، ومنها الحالات التاريخية/غير النشطة. |

لا يوجد P0 في النموذج الحالي. القاعدة لا تغيّر حالة الفرصة ولا تغلق المراجعة. عمر القضية معروض بالأيام، وتوزيع العمر الحالي موثق في open-review-reconciliation.json.

**SLA:** لا توجد أهداف زمنية رسمية أو تنبيهات تجاوز SLA مهيأة حاليًا. لم أضف مددًا اعتباطية؛ يظل العمر ظاهرًا للمراجعين.
