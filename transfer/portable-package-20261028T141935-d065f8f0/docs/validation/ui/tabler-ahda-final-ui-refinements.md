## تحسينات العرض

- **حالة الفرص:** تعيين ألوان ثابتة وفريدة للحالات الست الفعلية، وإظهار علامة اللون ذاتها في الحلقة والوسيلة والتلميح وشارات الحالة في جدول أحدث الفرص. يحافظ ترتيب الوسيلة على ترتيب شرائح الحلقة. يعرض التلميح الاسم العربي والعدد والنسبة.
- **أنواع الفرص:** تقليل الهامش العلوي وارتفاع الرسم قليلًا، وزيادة عرض الأعمدة وتحسين قراءة تسميات المحور.
- **المصادر الرسمية:** إبراز اسم المصدر والعدد، والإبقاء على الشعارات، وضبط المسافة والمحاذاة وسمك خط التناسب.
- **أحدث الفرص:** إبراز عنوان الفرصة، وتهدئة سطر الجهة، وتوحيد اتجاه التاريخ اللاتيني، وتقليل حشو الصفوف دون إزالة الروابط أو البيانات.
- **الخريطة:** إبراز بطاقة النقاط الموثقة ضمن ملخص المواقع، وتحسين وضوح زرّي «المواقع» و«الكثافة» وقراءة أعداد العناقيد. لم تتغير النقاط أو الإحداثيات أو طريقة العرض أو سلوك الانتقال.
- **أشرطة التناسب:** توحيد الارتفاع ونهايات الأشرطة الدائرية بين مؤشرات الدعم والمصادر وجودة البيانات والجهات؛ بقي شريط ترتيب الجهات أثخن قليلًا للدلالة على الترتيب.
- **ارتفاع البطاقات السفلية:** جمع بيانات آخر نجاح والتغطية في سطر مساعد مرن واحد، وتقليل الحشو في الجدول وصحة المصادر مع الحفاظ على قابلية القراءة.
- **الأرقام:** بقيت الأرقام اللاتينية `0–9` في قيم الرسوم والتلميحات والعناقيد والتواريخ.

## التحقق وسلامة البيانات

- نجحت فحوص التفاعلات والتصفية والتنقل والتصدير وتفاصيل الفرص والخريطة، إضافة إلى فحوص الألوان الفريدة وترتيب الوسيلة والتلميح وإعادة استخدام ألوان الحالة والتواريخ اللاتينية.
- راجعت اللوحة عند `1920×1080` و`1440×900` و`1366×768` و`768×900` و`390×844`؛ لم يظهر تمرير أفقي أو بطاقة أو عنوان متجاوز.
- لم تظهر أخطاء JavaScript أو طلبات API فاشلة. ظلت الأرقام `290` إجماليًا و`284` نشطة و`10` مصادر مفعّلة، و`176` فرصة ذات إحداثيات مطابقة و`114` غير ممثلة.
- نُشرت الواجهة فقط باستخدام `build frontend` و`up -d --no-deps frontend`. بقيت PostgreSQL وRedis وAPI والعامل والمجدول قيد التشغيل، وفحص `/health/ready` سليم. لم تتغير قاعدة البيانات أو بيانات الأعمال، ولم تُشغّل مزامنة.
