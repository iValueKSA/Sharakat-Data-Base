تشغيل منصة رَصْد على هذا الكمبيوتر (Windows / macOS / Linux) — لا يحتاج Docker

أول مرة فقط
  Windows: انقر مرتين على  Install Platform Requirements.bat
  macOS:   انقر مرتين على  Install Platform.command
  Linux:   bash sharakat.sh install

يثبّت الإعداد Python وPostgreSQL وخادم Redis لحسابك فقط، ثم يستعيد آخر حزمة نقل
(أو يستورد قاعدة SQLite القديمة)، ويفتح المنصة في المتصفح.

كل مرة بعد ذلك
  Windows: Start Platform.bat      macOS: Start Platform.command      Linux: bash sharakat.sh start

لإيقاف المنصة
  Windows: Stop Platform.bat       macOS: Stop Platform.command       Linux: bash sharakat.sh stop

تبقى بيانات المنصة محفوظة عند الإيقاف. بيانات دخول المدير المحلي موجودة في:
Local Admin Credentials.txt
(إذا استعدت بيانات من جهاز آخر، ادخل بحسابات ذلك الجهاز.)

Platform Status.bat يعرض حالة الخدمات، وVerify Installation.bat يتحقق من سلامة التثبيت.
السجلات في مجلد logs داخل:  %LOCALAPPDATA%\Sharakat   (macOS: ~/Library/Application Support/Sharakat)
التفاصيل التقنية: docs/runbooks/native-runtime.md
